# Synapse — Laboratorio de comunicación emergente

Synapse es un laboratorio experimental para investigar si poblaciones de agentes artificiales desarrollan señales útiles de comunicación mediante aprendizaje y evolución, sin asignarles de antemano significados lingüísticos.

## Objetivo

Construir un ecosistema 2D reproducible, observable y medible que permita comparar poblaciones con comunicación y sin ella, analizar señales, comportamientos y linajes, y probar hipótesis de comunicación emergente.

## Principios

- No programamos palabras ni significados para las señales.
- Las hipótesis se evalúan con métricas y experimentos controlados, no con apariencias visuales.
- Cada ejecución debe poder reproducirse usando su semilla y configuración.
- Documentar limitaciones y resultados negativos también es parte del proyecto.
